## 🎯 Purpose of This Playground

This repository serves as a foundational frontend playground. Each project is built without external libraries or frameworks to strengthen core competencies in:
* **DOM Manipulation & Event Listeners**: Handling user input, keyboard events, form submissions, and real-time state changes.
* **Asynchronous JS & REST APIs**: Fetching and parsing data using `fetch()` and `async/await`.
* **Browser Web APIs**: Working with `localStorage`, Web Speech API, Geolocation, and Canvas.
* **UI/UX & Dynamic Styling**: Implementing theme toggling (Dark/Light mode), drag-and-drop mechanics, and custom CSS animations.
